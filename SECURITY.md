# Security Policy

## Supported Versions

We actively monitor and provide security patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | ✅ Yes             |
| < v1.0  | ❌ No              |

## Reporting a Vulnerability

Security is paramount for healthcare platforms. If you discover a cryptographic, access delegation, or system vulnerability, please do **not** open a public GitHub issue. 

Please report all vulnerabilities responsibly by emailing security@vaultmedic.org.

### What to Include
* A detailed description of the vulnerability.
* Steps to reproduce the issue (including any mock payloads or XDR transaction inputs).
* Potential impact and suggestions for mitigation.

We will acknowledge your report within 24 hours and coordinate a public patch release. Thank you for keeping patient data safe!
